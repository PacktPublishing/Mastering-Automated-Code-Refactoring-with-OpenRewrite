  <summary><h2>About the book</summary>
<a href="https://www.packtpub.com/en-us/product/automated-code-refactoring-and-modernization-with-openrewrite-first-edition/9781808347832">
<img src="https://content.packt.com/B40034/cover_image_small.jpg" alt="Automated Code Refactoring and Modernization with OpenRewrite, First Edition" height="256px" align="right">
</a>

Automate repetitive refactoring and make large-scale code changes consistent and scalable with OpenRewrite. This book shows you how to use existing recipes and create your own transformations, helping you modernize codebases while significantly reducing the time and errors associated with manual changes.
You’ll begin with lossless semantic trees (LSTs), recipes, visitors, and styles to understand how OpenRewrite represents and transforms source code. You’ll then learn to find, configure, compose, and run recipes, add recipe sources, and integrate transformations with your build pipeline.
Next, you’ll create declarative recipes and Refaster templates before progressing to imperative recipes. You’ll work with visitors, cursors, shared data, non-isomorphic transformations, configuration options, testing, validation, and multiple visitors. All examples are visualized using Java as a programming language.
Written by freelance software engineer Ansgar Schulte, who brings many years of project experience and has taught more than 15,000 students, this book connects OpenRewrite concepts with techniques you can apply to real projects. By the end, you’ll be able to automate recurring refactoring tasks and build reusable recipes for your own codebases.</details>
